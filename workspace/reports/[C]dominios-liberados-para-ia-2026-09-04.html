Como aconteceu

A linha do tempo

Causa raiz

O bloqueio não vinha do Ghost

Confirmado direto no código-fonte do Ghost, na VPS: o robots.txt nativo dele é curto e genérico. Todo o bloqueio bot-a-bot e o cabeçalho Content-Signal vinham de uma camada da Cloudflare injetada por cima — a ferramenta "AI Crawl Control".

Tentativa 1 — via API

Bloqueada pelo próprio esquema de autenticação

PATCH /zones/{id}/bot_management devolvia 10405 Method not allowed for this authentication scheme para qualquer campo, mesmo com a permissão certa no token. Não é escopo — é a Cloudflare recusando token de API nesse endpoint específico, ponto.

Tentativa 2 — via painel, rota granular

Search / Agent / Training + Bot Preference Sync

A via "certa", recomendada até pelo assistente de IA embutido no próprio painel da Cloudflare. Configuramos Pesquisa e Agente em Allow, Treinamento em Block. O campo que deveria conectar essa política ao robots.txt real (bot_preference_sync_enabled) nunca saiu de false — e não apareceu em lugar nenhum da interface.

O que resolveu

Desligar o gerenciamento por completo

Security → Settings → Gerenciar robots.txt → Desative a configuração robots.txt. A Cloudflare para de injetar qualquer coisa, e cada origem volta a servir o próprio arquivo — que, nos 4 domínios, já não bloqueava ninguém. Confirmado bot por bot, com curl, sem cache.

Vale registrar

O que ficou de lição

Dashboard mente, arquivo servido não

A API do AI Crawl Control chegou a mostrar "Allow: /" pra todos os bots enquanto o robots.txt ao vivo ainda bloqueava tudo. A única fonte confiável foi testar o arquivo de verdade, sempre sem cache.

A ferramenta granular está quebrada nesta conta

Nem pelo painel, nem pela API, nem pelo próprio agente de IA da Cloudflare (que relatou "token expirado" no meio da sessão) foi possível fazer Search/Agent/Training refletir no arquivo real. A saída pragmática foi desligar tudo.

A troca teve custo

Desativar o gerenciamento também derruba o sinal explícito Content-Signal: ai-train=no. Hoje os domínios estão abertos para citação — o sinal formal de "não treine com isso" fica para uma implementação futura, na origem.
