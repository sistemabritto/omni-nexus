# Acesso Live

Um único link Live para `/live`, imediatamente após o acesso principal do Cockpit, em desktop e mobile. Os nove links anteriores conservam ordem relativa, nomes e permissões. Live segue a rota autenticada já existente, sem nova permissão artificial, alteração de flags, API ou microfone. Textos Live adicionados aos três locales.

QA local com APIs/WebSockets interceptados: admin vê dez links e viewer cinco permitidos; valida ordem, rótulos, clique `/live`, drawer, Tab/Escape e retorno do foco em 375×900/1440×900. Capturas e resultados nesta pasta; não representa validação Gemini nem sessão de produção. Não se promete ausência de scroll quando o décimo link exceder a altura disponível: alvos de toque continuam preservados.
