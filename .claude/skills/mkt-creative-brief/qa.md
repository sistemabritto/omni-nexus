# QA priorizado

Registrar: prioridade, peça/trecho, evidência, impacto, correção proposta, responsável e estado. Separar revisão textual de inspeção renderizada.

- P0 — bloqueia uso externo: claim sem prova, depoimento inventado, oferta/CTA incorretos, uso indevido de marca/assets ou mudança de identidade não autorizada. Remover claim ou pedir prova; nunca inventar uma correção factual.
- P1 — revisar antes de aprovação: hierarquia confusa, leitura/contraste/spacing, mobile com overflow, CTA ambíguo, desalinhamento com voz/tokens aprovados, duração de cena insuficiente. Sem render, registrar como hipótese de risco ou teste não realizado.
- P2 — refinamento: consistência entre peças, respiro, ritmo, redundância e detalhes de composição, sempre conforme marca e contexto.

Exemplo: P0 / headline “3× mais produtividade” / nenhuma fonte / promessa não sustentada / retirar número / Mako / pendente. P1 / landing mobile / sem screenshot / quebra de título desconhecida / inspecionar quando houver render / Canvas / não realizado. P2 / kit social / revisão textual / CTAs inconsistentes / alinhar ao objetivo confirmado / Pixel / proposto.

Saída: decisões confirmadas e hipóteses, fontes usadas, revisões efetivas, testes não realizados e próximos passos. Nenhum checklist equivale a prova de renderização ou autorização de publicação.
