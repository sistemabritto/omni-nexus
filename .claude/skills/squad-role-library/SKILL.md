# Biblioteca de responsabilidades do squad

As definições anteriores foram retiradas do catálogo de agentes. Seus métodos úteis permanecem como playbooks, não como agentes autônomos. A atribuição está em `scripts/squad-retirements.json`.

Use somente o documento pertinente à tarefa. Preserve os gates de aprovação, revisões independentes e isolamento de empresa. Nunca trate esta biblioteca como autorização para executar uma ação. Memória histórica migrada mantém a autoria e não é importada automaticamente para o contexto do Live.
