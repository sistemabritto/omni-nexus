# Matriz de temas — Sistema Britto

Adaptação da planilha "Ganchos para Temas de Ads" (3 abas: BRAINSTORMING,
IDEIAS DE ANÚNCIOS PADRÃO, IDEIAS DE ANÚNCIOS DE REMARKETING —
`docs.google.com/spreadsheets/d/15OMSexLytbxkO90EFuvxcld0INSodUVeBzy6UyxCmy8`),
preenchida em 10/09/2026 com o negócio real do Sistema Britto em vez do nicho
original (tráfego pago pra produtos digitais). A estrutura de colunas
(categoria de gancho) é a mesma; o conteúdo de cada célula é novo.

**Como usar:** cada célula é uma semente de tema, não um roteiro pronto.
Combine uma célula daqui com uma estrutura de `estruturas-de-linguagem.md` e um
gancho de `social-hook-bank` pra montar o roteiro completo.

## Aba 1 — Brainstorming (consciência do público)

| Dores que não sabe a causa | Problemas que já sabe a causa | Soluções que já conhece (e não resolvem tudo) | O que a audiência ainda não sabe sobre a oferta |
|---|---|---|---|
| Por que meu Instagram não converte em cliente mesmo com seguidor? | Não sei programar / tenho medo de mexer em servidor | Contratar agência de tráfego/social media | Dá pra montar sistema próprio (self-host) sem depender de agência |
| Por que eu trabalho tanto e a margem não aumenta? | Não tenho tempo pra atender todo mundo no WhatsApp | Comprar curso de programação | Existe uma call de 1h (R$147) que já sai com o PRD do projeto pronto |
| Por que meu atendimento no WhatsApp não fecha venda mesmo respondendo rápido? | Não sei precificar um serviço de IA/automação | Contratar atendente humano a mais | Ferramenta open source substitui boa parte do SaaS caro |
| Por que o projeto que comecei sozinho nunca sai do papel? | Não sei o que postar todo dia | Usar ChatGPT genérico sem estratégia | O primeiro passo não é "aprender IA", é mapear onde a operação perde dinheiro |
| Por que ninguém quer pagar o preço que eu cobro? | Gasto rios de dinheiro com SaaS que não resolve tudo | Comprar SaaS de automação pronto (caro, genérico) | Dá pra provar o valor pro cliente antes de vender (prova de conceito) |

**Avatares (tipos de audiência):**

1. Dono de negócio pequeno/médio sem tempo, quer IA no atendimento → `/whatsapp`
2. Profissional liberal/prestador de serviço querendo se posicionar sem virar refém de agência → `/sistema`, `/socialjobs`
3. Vibecoder que já sabe construir mas não sabe monetizar — quer virar "vibe seller" → `/sistema`
4. Quem quer sistema próprio (SaaS/CRM/bot) mas trava na parte de servidor → `/vps`
5. Quem quer aprender IA no negócio mas não sabe por onde começar, quer comunidade → `/zapclub`
6. Consultor/freelancer que vende IA pra outras empresas sem prova de conceito → `/sistema`

## Aba 2 — Ideias de conteúdo (ângulo)

| Categoria | Tema Sistema Britto |
|---|---|
| Gerar medo de permanecer onde está | É isso que acontece com quem demora pra automatizar o atendimento — o cliente vai pro concorrente que responde na hora |
| Acalme seus medos (existe uma forma) | Você não precisa saber programar pra ter um sistema seu |
| O que fazer se... (frustração comum) | O que fazer se meu Instagram não converte em cliente |
| História/Parábola | Laboratório de Insights (naufragou) → JURISMART (chegou tarde) → Voice Dream (decolou) — a lição de cada um |
| Ações convencionais que você sabe que são ruins | Contratar agência sem saber exatamente o que precisa resolver |
| Porque você nunca deve [suspeita que já tem] | Porque você nunca deve comprar ferramenta antes de mapear o processo |
| Porque [ação comum] não é a forma mais [x] | Porque aprender a programar do zero não é a forma mais rápida de ter seu sistema no ar |
| Você passa por [dor]? Isso acontece porque... | Você trava na hora de cobrar caro? Isso acontece porque falta prova de resultado, não falta coragem |
| Sacada/dica interessante | Uma pergunta só que resolve metade do problema de precificação |
| Você sabia que pode [desejo]? | Você sabia que pode ter um CRM próprio, de graça, no seu servidor? |
| Demonstração | Terminal rodando o comando que sobe o servidor |
| Jeito certo vs. jeito errado | Vender IA sem prova (errado) vs. vender com prova de conceito rodando (certo) |
| Prova/depoimento | Números reais dos próprios posts (reach, conversão) — nunca número inventado |
| Maneiras pouco conhecidas de [desejo] sem [dor] | Maneiras de crescer no Instagram sem gastar em tráfego pago |

## Aba 3 — Remarketing / quebra de objeção (funil `/sistema` — call de PRD, R$147)

| Categoria | Tema Sistema Britto |
|---|---|
| Como fazer [x] mesmo se [objeção comum] | Como ter um sistema rodando mesmo se você não sabe programar |
| Porque começar agora | O preço da call (R$147) não muda, mas o custo de continuar travado sozinho, sim |
| "Isso é caro?" | R$147 por um documento de escopo evita gastar 10x mais contratando errado depois |
| "E se não funcionar pro meu caso?" | A própria call já diagnostica se o caso serve pra automação ou não |
| "Já tenho um dev/agência, ainda serve?" | Serve pra definir o escopo antes de contratar, e a equipe já executa com PRD em mãos |
| Depoimentos batendo as objeções mais comuns | (preencher com depoimento real quando existir — não inventar) |
| Perguntas respondidas sobre a call | O que exatamente entra na 1h, o que sai no PRD, pra quem não serve |
| Vantagens da call | Sai com documento, não com promessa |
| O que a call entrega que ninguém espera | O PRD fica com você mesmo que decida não contratar ninguém depois |
| Capítulo/etapa da call | Diagnóstico → mapeamento do gargalo → escopo → PRD entregue |
| Garantia | **[confirmar com o Felipe se existe garantia formal antes de usar este ângulo]** |
| Benefícios escondidos | Serve também pra convencer sócio/investidor com documento em mãos |
| Urgência real (não fabricada) | Só usar se houver motivo real (agenda fechando, etc.) — nunca inventar prazo falso |

## Regra de uso

Todo número, caso ou depoimento citado tem que ser real (mesma regra do
`esteira-de-conteudo.md` §2.1) — os únicos casos fechados pra citar são
Laboratório de Insights, JURISMART, Voice Dream e Omni Nexus. Campos como
"Garantia" e "Urgência" ficam explicitamente em aberto até serem confirmados
— nunca preencher com algo inventado só pra completar a célula.
